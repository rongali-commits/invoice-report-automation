# Security policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest published release.

## Reporting a vulnerability

Use GitHub's **Security** tab to report a vulnerability privately. If private vulnerability reporting is unavailable, email `hello@noerong.com`.

Include the affected component, impact, reproduction steps, and any suggested mitigation. Do not open a public issue for an undisclosed vulnerability, and do not include credentials, real invoices, customer data, or production records in the initial report.

We aim to acknowledge reports within three business days and will coordinate validation, remediation, and disclosure with the reporter.
